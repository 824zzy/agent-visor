Agent Visor 2.8.0

  • Support for Paseo profiles, exact cmux surface navigation, and compatible Herdr client navigation.
  • Source and profile details in pill hover panels, plus compact Copilot credit usage.
  • Attention-first unopened completions and notification clicks that open the original session.
  • More accurate Claude and Codex question, permission, working, and completion states.
  • Verified Codex CLI ownership takes priority over Desktop routing; unavailable routes fail safely.
  • Improved multi-display menu placement and native navigation diagnostics.

Requires macOS 14 or newer. Herdr exact navigation requires a compatible Herdr build exposing guarded client navigation and native session identity. Codex CLI routing also requires Herdr's Codex SessionStart integration and a verified current frontend binding. Existing sessions without a genuine binding may remain unavailable until a normal session start or resume supplies it; live acceptance of the current long-running CLI route is still pending. Agent Visor does not bundle or upgrade Herdr.

Updates open GitHub for manual installation. Roll back with v2.7.1 build 55 if needed.
