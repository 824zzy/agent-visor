What’s new

  • One searchable session workspace. Browse Needs you, Ready to continue, In progress, and History sessions with ranked search, keyboard navigation, responsive rows, and preserved browser state.
  • Owner-first navigation. Row click and Return use Open in <owner> for the canonical application or terminal. Open Chat remains a separate action for supported Agent Visor conversation views.
  • Provider-aware Chat. View bounded provider history with grouped work, reasoning, tools, images, questions, approvals, pagination, Details, and capability-correct composer actions.
  • Electron settings and native services. Configure theme, content size, menu-bar pills, full-screen visibility, shortcuts, notifications, Chat visibility, Codex usage, and agent connections from one Settings surface.
  • Safer local integrations. Claude Code, Codex, and Auggie use explicit connection controls; Pi installs only Agent Visor’s bundled metadata-only extension; Cursor and Zed remain read-only.
  • Responsive and accessible controls. Sessions and Chat support keyboard navigation, named actions, read-only states, and content scaling from 80% through 250%.

Improvements and fixes

  • Provider-origin filtering removes known injected task metadata while preserving user-authored quoted content, links, images, and unknown or ambiguous records.
  • Chat delivery uses request and provider identity, bounded recovery, safe cancellation, and per-session draft restoration.
  • Menu-bar recent-session ordering, overflow counts, Ready acknowledgment, and display/full-screen behavior use source-backed evidence and stable attention rules.
  • The signed native helper keeps Accessibility, global shortcuts, display topology, notifications, Dock badges, and exact owner focus behind a narrow macOS boundary.
  • Settings use a private mode 0700 directory, mode 0600 file, and atomic replacement. Known Swift preferences migrate into the Electron settings store.

Known limitations

  • Inspect, hide, unhide, and custom-recording controls are deferred from the first Electron release.
  • Claude usage is hidden until a provider-authoritative credential route exists.
  • Cursor Chat is read-only. Zed-hosted Chat is read-only and exact sidebar/thread reveal is best effort. Auggie remains observe-only.
  • Automatic Pi session restoration after a physical macOS reboot has not completed real-machine acceptance and is outside the verified 2.7.0 release scope.
  • Historical, ended, and unsupported sessions are read-only. Sending and approval controls require a verified provider route for the current session.
  • Updates validate a newer three-part version, matching HTTPS GitHub ZIP URL, and expected Ed25519 signature metadata shape before opening its GitHub release page for manual installation. The Electron updater does not cryptographically verify ZIP bytes; Sparkle Ed25519 signing still protects published archive metadata for compatible consumers. The app does not install updates in place.
  • The cutover copies only the staging Electron profile (~/Library/Application Support/Agent Visor Next) into the production profile (~/Library/Application Support/Agent Visor) when the source is not live. A live source defers import, leaves that source untouched, and excludes transient Electron lock markers from the copy. Provider transcripts, databases, hooks, and live session records remain in place and are outside this profile operation.

Rollback: the exact rollback artifact is the public Swift Agent Visor v2.6.1 build 53. Quit Agent Visor 2.7.0, install the verified v2.6.1 ZIP, and launch it from /Applications. If you installed with Homebrew, do not run brew uninstall --zap while retaining diagnostic profiles; the zap operation removes the application data paths.
