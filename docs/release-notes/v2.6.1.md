# Agent Visor 2.6.1

## What’s new

- **Sessions now return to their owning app.** Row clicks and Return open Ghostty, Codex, Zed, or another owner. Open Chat stays separate.
- **Rapid session switches are reliable.** Agent Visor runs focus requests in order, skips stale requests, and keeps the latest destination.

## Improvements and fixes

- Removed the invisible external-display menu-bar click target and the synthetic notch on displays without a physical notch.
- Fixed Pi names before the first message and across custom transcript records with nested identifiers.
- Moved blocking process, liveness, transcript, and machine reads away from shared session threads, with bounded subprocess deadlines.
- Clarified Sessions and Chat controls with separate hover surfaces, larger Back targets, and direct `Open in <owner>` labels.
- Hardened provider ownership, watcher scope, phase evidence, and delayed-result freshness without changing source authority.
