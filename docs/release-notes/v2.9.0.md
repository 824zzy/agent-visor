# Agent Visor 2.9.0

Agent Visor 2.9.0 makes the Sessions window quieter and more consistent, retains closed conversations, and improves exact terminal navigation.

## What's new

- Keep observed conversations in Saved across app restarts, with readable Chat history when available.
- Resume supported closed Claude Code and Codex CLI conversations explicitly in Ghostty. Agent Visor checks the saved conversation, executable, profile and folder before reopening it; uncertain attempts are reconciled before another launch.
- Locate a moved project folder or repair supported provider references, and remove eligible saved records from Agent Visor without deleting source transcripts or stopping a runtime.
- Use fixed source, Chat and More columns in Current and Saved. Read-only access says **Read chat**; routine resume guidance and occasional maintenance commands are available through **More**.

## Improvements and fixes

- Current and Saved use verified presence rather than treating every catalog entry as a live conversation. Ordinary saved records stay neutral; genuine detection failures retain targeted recovery.
- Pills and Sessions share lifecycle and attention evidence. Real unanswered questions and permissions remain yellow, and busy turns remain orange.
- Gray inactive pills follow ready pills. Metadata-only updates no longer revive old completion flashes.
- Prepared Ghostty and Herdr routes move discovery work off normal pill clicks while preserving exact session identity checks. Verified Codex CLI bindings take precedence over Desktop catalog copies.
- Cross-source deduplication preserves verified live conversations and their resume lineage without merging sessions by title or folder alone.
- More supports keyboard activation, keeps search and reading position stable, and fits constrained windows and larger text sizes.
- The Homebrew cask uses current declarative installation steps while preserving the release signature. Update Homebrew before installing or upgrading.
- The Dock badge is removed, and badges left by older versions are cleared on launch. Pills, notifications and unread attention remain available.

## Requirements and known limitations

- macOS 14 or newer. The Electron app uses the existing AgentVisor Release signing identity.
- Automatic closed-session resume is currently supported in Ghostty only and requires verified saved provenance. Herdr and other unsupported hosts provide manual-resume guidance; Agent Visor does not guess another terminal or launch a duplicate session.
- Exact Herdr navigation requires a compatible Herdr build and a verified client/pane binding. Codex CLI background-server routing requires a genuine thread-to-pane binding. Agent Visor does not bundle or upgrade Herdr.
- Unknown presence does not prove a conversation is closed or safe to resume. Genuine detection failures retain Retry; unsupported resume remains a normal limitation.
- Cursor Chat remains read-only. Zed exact sidebar reveal is best effort; Auggie remains observe-only. Automatic Pi restoration after a physical macOS reboot remains unverified.
- Updates open the matching GitHub release for manual installation; Electron does not install updates in place.
