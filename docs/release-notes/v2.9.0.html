Agent Visor 2.9.0

  • Retain observed conversations in Saved across restarts, with readable history and guarded, explicit Ghostty resume for supported closed Claude Code and Codex CLI sessions.
  • Consistent source, Chat and More columns, compact Read chat labels, and quieter on-demand resume guidance.
  • Locate moved folders, repair supported provider references, or remove eligible saved records without deleting source transcripts or stopping runtimes.
  • Verified Current/Saved presence and shared pill/session status evidence; real questions stay yellow and busy turns stay orange.
  • Improved exact Ghostty/Herdr navigation and cross-source deduplication, with discovery work moved off normal pill clicks.
  • Inactive gray pills follow ready pills; metadata-only changes no longer revive completion flashes.
  • Keyboard-accessible More menus fit larger text and constrained windows while preserving reading position.
  • Current Homebrew installation steps preserve the release signature. Update Homebrew before installing or upgrading.
  • No Dock badge; badges from older versions are cleared while pills, notifications and unread attention remain available.

Requires macOS 14 or newer. Automatic closed-session resume is Ghostty-only and requires verified saved provenance. Herdr exact navigation requires a compatible Herdr build and a verified client/pane binding; Agent Visor does not bundle or upgrade Herdr. Unsupported hosts retain manual-resume guidance. Cursor Chat remains read-only, Zed exact reveal is best effort, Auggie remains observe-only, and automatic Pi restoration after a physical reboot remains unverified.

Updates open GitHub for manual installation. Roll back with v2.8.0 build 56 if needed.
