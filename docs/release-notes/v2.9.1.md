# Agent Visor 2.9.1

This hotfix restores navigation to Ghostty conversations after upgrading.

- Fixes the “The terminal cannot be focused” error when opening an existing Ghostty session.
- Selects the exact terminal after bringing Ghostty forward, including windows whose titles follow the working directory.
- Restores exact Herdr-in-Ghostty navigation when Ghostty reports an unknown working directory.

Requires macOS 14 or newer and Apple Silicon. Herdr navigation still requires a compatible Herdr installation.

For Homebrew upgrades, run `brew update` followed by `brew upgrade --cask 824zzy/agent-visor/agent-visor`. Existing application data is preserved.
