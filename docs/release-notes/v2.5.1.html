What is fixed

  • Fixed severe CPU and memory pressure in large Pi sessions. Agent Visor now coalesces transcript refreshes, skips unchanged files, and decodes only appended JSONL records after the initial index build.
  • Prevented Agent Visor from replaying completion notifications, sounds, and visual attention while a session remains continuously Ready, including during transcript hydration or attachment metadata changes.
  • Stabilized accidentally resumed Pi sessions by keeping the first live runtime as the session owner until it exits, preventing PID/terminal oscillation and misrouted actions.
  • Reduced menu-bar packing work by caching fixed-font pill and overflow measurements without changing session priority or collision safety.

Improvement

  • Sessions and Chat now share one persistent Content font size setting from 80% to 250%. Use Command-Plus, Command-Minus, or Command-0 to adjust or reset it without affecting menu-bar pills and fixed controls.

Pi still performs one initial transcript index build after Agent Visor launches or first opens an uncached session. Later unchanged checks read no transcript bytes, and normal growth reads only the appended range.
