# Agent Visor 2.8.0

Agent Visor 2.8.0 improves session navigation, attention states, and support for Claude Code terminal hosts.

## What's new

- Discover Claude Code sessions managed by Paseo, including provider profile details.
- Open the exact cmux surface for a session, with window activation and focus checks.
- Navigate supported Herdr sessions through verified single-client routes.
- Show source application and profile details in the existing pill hover panel without widening pills.
- Show GitHub Copilot credits in a compact CP usage pill when account data is available.

## Improvements and fixes

- Unopened completions take priority in the menu bar and retain visible attention until acknowledged.
- Notification clicks open the original session when available. Unread attention clears only after successful navigation.
- Claude Code agent overviews and pre-warmed spare processes no longer create phantom conversation pills. Conversation and child-agent views retain their verified session routes.
- Completed idle Claude jobs show Ready, while real questions and permission requests remain yellow and busy turns remain orange. Stale, unverified jobs move to History.
- Codex unanswered asynchronous questions remain yellow; answered questions and questions belonging to completed turns no longer leave stale pending status.
- Verified Codex CLI routes take priority over the Desktop representation of the same thread. Routes are checked again at click time; ambiguous or missing terminal identity reports an unavailable route rather than opening the wrong app.
- Multiple Codex homes and app instances retain separate session ownership.
- Cross-monitor menu placement uses the menu owner on the pill display.
- Native navigation diagnostics and command cleanup improve failure reporting and resource handling.

## Requirements and known limitations

- macOS 14 or newer. The app remains signed with the existing AgentVisor Release identity.
- Herdr exact navigation requires a compatible Herdr build exposing guarded client navigation and native session identity. Agent Visor does not bundle or upgrade Herdr.
- Codex CLI navigation needs a verified current frontend binding. Herdr's Codex SessionStart integration must be installed; existing sessions without a genuine binding may remain unavailable until a normal session start or resume supplies it. The current long-running CLI route has not completed live acceptance.
- Ghostty overview suppression remains enabled. When exact conversation ownership cannot be verified, Agent Visor does not guess a terminal from folder or recency.
- Cursor Chat is read-only. Zed-hosted Chat exact sidebar reveal is best effort; Auggie remains observe-only.
- Automatic Pi restoration after a physical macOS reboot remains unverified.
- Updates open the matching GitHub release for manual installation; Electron does not install updates in place.
