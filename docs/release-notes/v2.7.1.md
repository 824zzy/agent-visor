# Agent Visor 2.7.1

Agent Visor 2.7.1 is a maintenance release for the Electron app. It fixes
session states that did not match reality, makes Claude Code chats far easier
to read, and adds Alfred session search.

## What’s new

- **Alfred session search.** Find sessions from Alfred, sorted by relevance and recent activity, and open the owner application or terminal directly.
- **Informative turn headers in Chat.** A collapsed turn now says what it did and how long it took, for example “Worked 6m 2s · Edited 3 files · Ran 15 commands · 2 failed”, instead of “Worked · 10 steps”. The separate “Turn duration” row is gone.
- **Readable Chat typography.** Real heading sizes, tighter block spacing, quieter tables, visible inline-code chips, nested lists, and larger code and system text.
- **Provider-backed composer controls.** Composer menus follow the provider’s own capabilities, keep drafts when Codex owns the conversation, and report session state clearly.

## Improvements and fixes

- Sessions no longer turn orange (“Needs attention”) one minute after every turn. Claude Code’s idle notifications never change a session’s phase.
- Dead Codex desktop turns from months ago no longer show as “Agent is working”. Transcript markers expire after 30 minutes without new writes, and a completed Codex task moves to History after 30 minutes, matching Claude Desktop and the Swift app.
- Finished turns start collapsed, even when a step failed. A turn stays open while the daemon reports it working, and a turn that ended on a tool call no longer reads as “Working…” forever.
- Slash-command echoes such as `/rename` and `/context` render as the typed command instead of raw markup, in both the Swift and Electron chats.
- Menu-bar pills: Working ranks before unseen completions, unseen completions stay green until activated, pill reordering slides instead of jumping, pills stay stable during clicks, and Agent Room sessions are hidden from pills. Native session menus show seven days of activity.
- Session browser: completed sessions age into History and are ordered by recent activity, ready sessions share one heading with unseen completions first, Claude Desktop completion state and pill navigation are reconciled, and unarchived Codex conversations stay listed.
- Chat delivery keeps reads independent of Codex writer ownership, acquires on Send, and releases after completion or Stop. The composer no longer shows the native focus outline.

## Known limitations

- Inspect, hide, unhide, and custom-recording controls remain deferred.
- Claude usage is hidden until a provider-authoritative credential route exists.
- Cursor Chat is read-only. Zed-hosted Chat is read-only and exact sidebar/thread reveal is best effort. Auggie remains observe-only.
- Automatic Pi session restoration after a physical macOS reboot has not completed real-machine acceptance.
- Updates validate a newer version, matching HTTPS GitHub ZIP URL, and Ed25519 signature metadata, then open the GitHub release page for manual installation.

**Rollback:** install the previous Electron release, Agent Visor v2.7.0 build 54, from GitHub Releases. The Swift v2.6.1 build 53 remains available as the older rollback.
